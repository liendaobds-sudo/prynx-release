## Chặn #2 — Verify bản release thật (🟠)
Chạy `build_production.ps1 -Release` → cài trên máy sạch, rồi theo checklist Mục 9.6/15:
- Đăng nhập license thật → dùng 1 tính năng backend (merge/imposition) chạy được (token Ed25519 end-to-end).
- Bấm **Tách nền** → onnxruntime load OK (xác nhận native DLL bundled — Mục 20/22).
- Bật diag (`%APPDATA%\PrynX\logs\.security_diag`) → `security.log` ghi `enforce=true dev_mode=False pubkey=embedded` → xoá file diag.
- Sửa 1 byte file đã cài → app báo tamper + thoát.
