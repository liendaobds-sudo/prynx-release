# LO133 — Type boundary DataMergeTool

Ngày: 2026-08-24
Phạm vi: `desktop/src/components/preprocess-tools/DataMergeTool.tsx`

## Findings

- Baseline ESLint mục tiêu: 26 lỗi `@typescript-eslint/no-explicit-any`.
- Không phát hiện lỗi `react-hooks/exhaustive-deps` trong file.
- Các `catch` dùng `any` và PapaParse callback dùng `any` làm mất kiểm tra kiểu ở boundary.

## Thay đổi an toàn

- Thêm `DataMergeField`/`DataMergeChange` dựa trên `VdpToolField`, khai báo các thuộc tính VDP/QR/barcode/image đang dùng.
- Đổi callback, field mapping, PapaParse result và các `catch` sang kiểu cụ thể/`unknown` với helper `errorMessage`.
- Dùng type guard cho dòng CSV và type adapter setter để không đổi hợp đồng setter ở các component gọi DataMerge.
- Chỉ thêm type assertion cho các giá trị select có union (barcode, QR error correction, text align); không đổi payload hay luồng xử lý.

## Verify

- `npx eslint src/components/preprocess-tools/DataMergeTool.tsx --format json`: đạt, 0 error / 0 warning.
- `npm run typecheck -- --pretty false`: DataMergeTool không còn lỗi; toàn frontend còn 4 lỗi có sẵn ở `src/components/workspace/LivePageFrame.tsx:5601` (tọa độ có thể undefined), ngoài phạm vi LO133.
- Không có test riêng cho DataMergeTool được tìm thấy trong phạm vi lô; chưa chạy toàn bộ Vitest.

## Rủi ro còn lại

- Cần xử lý riêng 4 lỗi type ở LivePageFrame trước khi kết luận typecheck toàn repo đạt.
